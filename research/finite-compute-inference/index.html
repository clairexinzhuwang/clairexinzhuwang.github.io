How much uncertainty comes from the data—and how much from the optimizer?

Many ranking, metric-learning, and comparison-based models are trained from pairs or higher-order tuples. This project develops inference for the estimator a finite stochastic optimization run actually returns—not an idealized exact optimizer.

Main idea

Two sources of error

Overview

Many statistical objectives average losses over pairs or tuples, making optimization expensive even when each score is cheap. This work develops uncertainty quantification for the unaveraged final iterate produced by tuple-sampled stochastic gradient descent at a prespecified stopping horizon. It shows that error has two distinct sources: variation from the observed data and algorithmic variation from sampling a finite number of tuples. These components converge on different scales—sample size and tuple budget—and become asymptotically independent. A single run can estimate both pieces using terminal tuples and paired, sample-specific anchor draws, avoiding complete enumeration and repeated optimization. The resulting covariance estimate supports coordinatewise Wald intervals across small-, finite-, and large-budget regimes. Theory covers generalized K-sample U-statistic objectives under fixed-dimensional convexity and smoothness conditions, with specialized arguments for smoothed rank regression and role-sampled triplet learning. Simulations and two data analyses demonstrate variance calibration, computational savings, and the consequences of ignoring optimization uncertainty.

Technical details

The data component operates at the sample-size scale, while the optimization component operates at the tuple-budget scale. If Λ = BT/n approaches a finite positive limit, both appear in the first-order covariance; if it approaches zero, optimization dominates; if it diverges, the data component dominates.

The inverse-Hessian fixed gain minimizes the first-order optimization covariance among stable fixed matrix gains. The last-iterate comparison concerns fixed-fraction averaging of this same 1/t trajectory; it is not a comparison with differently tuned Polyak–Ruppert procedures.

Ownership and boundaries

Contribution and scope

My contribution

  • Mathematical analysis and proof development
  • Numerical implementation
  • Simulation design and empirical validation
  • Reproducibility testing

Current scope

  • Fixed dimension and tuple order
  • Independent observations, a unique interior population minimizer, and positive-definite local curvature
  • Prespecified horizon and fixed minibatch along formal asymptotic sequences
  • Adaptive stopping, dependence, growing dimension, degenerate first projections, and nonconvex objectives require new analysis

Stress-test boundary. Growing-minibatch experiments reaching n=1,000,000 are numerical stress tests, not validation of the fixed-minibatch theorem.
