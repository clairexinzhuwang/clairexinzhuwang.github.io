What I preserve

Before the run

  • Frozen design and configuration hashes
  • Separated random-number streams
  • Declared endpoints and failure rules

After the run

  • Replication-level or aggregated machine-readable records
  • Failures retained in denominators
  • Audit scripts that re-derive displayed summaries
  • Data-source checksums and explicit non-redistribution notes
