# clairexinzhuwang.github.io

Public research portfolio for Xinzhu (Claire) Wang.

The site presents two doctoral research directions through high-level,
preprint-stage summaries. It describes the questions and their practical
relevance without publishing manuscript titles, algorithms, theorems,
numerical results, figures, or code.

It also includes role-specific entry points for product data science and
health/biostatistics, public talks and artifacts, a web CV, and a cleared
randomized-experiment case. Technical materials will be added only after a
citable public version exists and the authors approve release.

The static pages are exported from the companion Sites source project. Run the
repository checks with:

    node --test tests/site.test.mjs
