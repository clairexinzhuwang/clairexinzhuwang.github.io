# Public inspection notice

This directory is published so prospective collaborators and employers can inspect
the implementation, frozen configuration, audit logic, and stored result records
associated with the research project *Inference from stochastic gradient descent
for U-statistics*.

The manuscript PDF and source are not distributed here. The public datasets are not
redistributed; download instructions and checksums are provided under `real_data/`.
